## 如何运行程序
1. 从 [Releases](https://github.com/SyrieYume/F7dDemo/releases) 下载最新版的 `F7dDemo.zip`

2. 将 `F7dDemo.zip` 解压到任意位置

3. 运行其中的 `永远的7日之都(Demo).exe`

4. 按照控制台提示，用浏览器打开 `http://localhost:3050` (默认是使用 3050 端口，如果这个端口被占用，就是其它端口)

5. 如果遇到 **Bug**，欢迎在 [Issues](https://github.com/SyrieYume/F7dDemo/issues) 中提出


## 如何手动编译本项目

### Web前端部分
1. 下载和安装 [**Node.js**](https://nodejs.org/)
   
2. 下载项目的源代码，解压到任意目录

3. 在项目目录下执行以下命令：
```powershell
npm install
npm run build
```
4. 生成的文件在项目目录的 `dist` 路径下
